# İzleva — tanıtım sayfası (geçici)

Tek bir statik sayfa: `index.html`. Kaynağı ayrı bir depoda duran uygulamanın
`/tanitim` rotasından `npm run build:landing` ile üretildi.

**Bu adres geçicidir.** Sözleşmeye, faturaya, kartvizite veya reklama yazılmaz
(`D-012`). `robots.txt` her tarayıcıyı dışarıda tutuyor.

Ürün henüz yayında değil ve bu sayfa hiçbir kişisel veri toplamıyor: form yok,
analytics yok, çerez yok.
